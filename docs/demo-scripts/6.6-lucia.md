# 6.6 Spanish-speaking patient — "Lucía"

## Purpose

Show that the product refuses to enroll a woman in a language whose safety-critical content is
not approved, that she still counts in the denominator, and that the practice gets a human-only
outreach item rather than an English message. The second branch shows what changes once the
class is approved: she enrolls, and ordinary items that exist only in English fall back with the
marker.

Audience: women (default; through an interpreter) and practice stakeholders (default). Open with
the cross-scenario block and close with the paired questions for practice audiences.

## Persona

Lucía, adult, preferred language Spanish (usted), Medicaid, interpreter need. Delivered Wednesday
2026-04-15; registered by the coordinator on Thursday 2026-04-16.

## Branches and starting clock

| Branch | Starting clock | What is on screen |
|---|---|---|
| `lucia_blocked` | Thu 2026-04-16 09:05 | Registered minutes ago; not offered enrollment; outreach item open |
| `lucia_enrolled` | Sat 2026-04-18 14:06 (day 3) | Enrolled; the day-3 check-in just answered in Spanish with the fallback marker |

How this build produces the block: the enrollment service blocks by itself when the Spanish
safety-critical class is missing or unapproved in the content index (FR-63a). In this build the
class is present as a placeholder translation (approver `placeholder-translator`,
`placeholder: true`), so the service allows enrollment; the coordinator records the not-offered
status and the outreach item by hand, and the branch description says which of the two happened.
The `lucia_enrolled` branch checks the same index at load time and stays blocked, with the missing
ids in its description, until the class is approved.

## Expected events

Blocked: `patient_registered` (locale es), `eligibility_changed` (not_offered,
language_content_unavailable), `queue_item_created` (follow_through, note "interpreter or
Spanish-speaking staff needed", placeholder episode id `no-episode:pt-lucia`),
`queue_item_acknowledged`, `queue_item_resolved`, `staff_time_logged` (20). Never: `enrolled`.
Enrolled branch: `enrolled` (performed_by staff), `contact_logged` and
`initial_contact_confirmed` (day 1), `checkin_submitted` with `barrier_item_created`
(interpreter), the usual visits, screens, summaries and `episode_closed`.

## Discovery questions

  Who would you want to call you?"
- Practices: "What share need Spanish, who calls them today, who approves the Spanish text?"
- Practice (closing, paired): clinician, "Would you recommend this to patients?"; budget owner,
  "Would you pay for it, from which budget, at which structure?"
